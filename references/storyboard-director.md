# 分镜生成主规则

本文件替换此前分镜生成规则。输出连续分镜式动态漫画，表现形式参考用户样片；每格是独立设计的漫画镜头。人物动，镜头不替人物动。禁止做同一背景上不断换人物姿势的插画幻灯片。

制作入口按 [动态漫画制作向导](production-wizard.md) 和 [总控复用边界](v10-control-system.md#已有分镜的复用边界) 执行。Skill 根据 brief 和角色/风格参考生成独立漫画分镜；用户明确授权复用的合格分镜可作为最终 shot 候选，只有参考用途的图片才用于指导新绘。`source_panel` 记录来源标识，不代替授权、master 或图层复核。

## 场景与角色

同一地点先建立场景空间记录 scenes：空间关系、时间、光线、主要物件及位置，美术风格沿用 brief。不同镜头共享这份空间事实，不机械共用背景图片。每次切镜根据人物、动作、叙事重点重新选择机位和构图：全景、不同方向中景、近景、特写、双人对话等。背景透视、可见物件和遮挡必须随机位合理变化；不能只修改标签，也不能缩放同一张图片假装新景别。

固定角色跨镜保持发型、发色、五官、脸型、服装、体型和配饰。改变的是姿势、表情、视线、动作、景别和角度，禁止每镜重新设计角色。Character Reference 锁身份；master 锁当前镜的构图。已经确认的同一镜头进入动画阶段后不再重构场景。

## 人物表演与动态

人物默认状态为静止。只有明确事件触发动作：说话→嘴型变化；听到信息→眼神或表情变化；自然停顿→偶尔眨眼；情绪变化→一次短暂头部/身体动作；明确行为→对应手势。说话者按台词表演：自然轻微嘴部开合，依情绪微偏头、眨眼，看向交流对象或物件，必要时一个简单手势。倾听者不能机械静止，按听到的信息安排视线移动、眨眼、微转头或表情反应，记录在 listening_reactions。动作使用准备→动作→停顿/回稳节奏，完成后回到稳定状态。禁止持续上下浮动、左右摇摆、缩放、机械呼吸、固定频率眨眼或全身同步运动；一次只突出一个主要动作。

机位在每镜内原则上固定。禁止整图放大、缩小、左右或上下平移、旋转、拉伸制造人物动态。背景稳定，动作来自局部人物素材。复杂连续动作优先通过新的漫画分镜表达；如果需要移动头部、身体、手臂，先补全遮挡和分离部件，不能拖动脸部矩形补丁。

此前固定微动作模式的“配角基本静止、每人一次眨眼”不再是通用分镜限制，仅当用户明确要求 fixed-camera-micro 时启用。

## 连续性与切镜

先拆 Narrative Beats，再按信息、动作、视线或情绪变化拆 Shots。每镜写 incoming_state、outgoing_state、cut_reason、handoff。连续性必须能解释：看到消息→抬头告知→倾听者反应→回应。禁止无原因换姿势、跳机位、换背景空间。坐/站、在桌后/桌前、拿起/放下这类大姿态和位置变化，要么在某一镜里演出来，要么在跨镜时保持不变，不能在 CUT 后直接换成另一种状态。分镜里每个角色可以写 `posture`（standing、seated、lying、kneeling、crouching、riding、other）和 `placement`（如“办公桌后”），姿态或位置在同一场景里变化的那一镜写 `posture_change` 说明怎么演出来；`validate` 会在生图前对没交代的变化给出 `posture` / `placement` 提示，括号里的备注不算位置变化。

正反打（A 朝右说话 → B 朝左回应）时，两镜背景应来自相反方向：A 身后是房间一侧，B 身后是对面一侧。两镜都画同一面墙会让观众误以为两人站在同一边。`validate` 在生图前就会对这样的相邻单人镜头检查 `background_view` 是否相同（`reverse_background` 提示），`compile` 还会在后一镜的提示词里写明“这是反打，背景必须是对面一侧”；成片阶段质量闸门另有 `reverse_shot` 提示。每镜的 `continuity_instructions` 同时写入角色的姿态和位置，要求与上一镜保持一致或按 `posture_change` 画出变化。

每次切镜回答“为什么此刻需要切到这个画面？”可以是呈现新信息、展示反应、强调细节或形成笑点，不能只是“换个画面避免重复”。用 next_shot_id 指向实际下一镜，末镜设 null；handoff 说明动作、视线或情绪如何承接，末镜说明如何收束。更换场景应交代时间或空间转移，不把不同空间画成同一个空间。

字幕由后期系统添加，不生成在漫画图片中。表演、字幕、配音同一时间轴；一句台词结束后根据剧情需要保留短暂反应时间，再硬切。reaction_hold_frames 明确记录对白结束到镜尾的反应帧数，可以为0，不机械留白，也不强制对白一完立即切镜。

## 漫画表现

普通对白自然、克制；震惊、尴尬、愤怒、吐槽、反转或笑点可采用明显表情变化、汗滴、青筋、黑线、震惊线、速度线、背景简化或夸张反应。仅在情绪重点出现，不能所有镜头都高强度动态。背景简化是明确的漫画表现选择，必须保留场景身份和恢复衔接，不能掩盖不连贯空间。

`motion_plan` 0.3 要求 scenes 与每镜 direction。基础角色 action/expression/gaze 和 dialogue 继续使用现有字段，避免复制两份台词或时间轴。compile 将这些结构化字段输出为完整 storyboard_review.md；同时向逐镜 master/acting 提示词传入场景空间和相邻镜头承接信息。

## 验收

人物外形连续；场景空间连续；背景构图不机械复用；动作与台词存在因果；说话者像在说话、倾听者像在听；不同景别来自新分镜而非图片缩放。查看相邻镜头接触表，同时核对空间记录、视线与台词时间。

自动检查结构完整性、场景引用、下一镜链接、倾听者反应记录、反应时长、完全相同背景素材复用，并提示重复背景视图标识。不能自动证明透视正确、反应自然或新背景确实改变了机位；近似背景复制、空间跳变、无因果换姿势必须经视觉复核返工。不得为通过检查编造理由、改ID、微改像素或改变人物身份。
