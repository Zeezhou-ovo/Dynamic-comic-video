# 漫画演出与视听反馈

本规则建立在角色一致性、事件驱动动作和音频时间轴之上，负责视觉特效、重点字幕、音效、环境音、情绪强化、反应镜头和笑点停顿。特效只服务于剧情、信息重点、情绪或笑点，普通对白保持干净，整体形成“平静 → 强调 → 平静”。

## 事件分级

- `ordinary`：日常对白和普通信息，不添加明显漫画特效。
- `emphasis`：重要信息或关键词，可使用一个轻量字幕强调或一个轻量音效。
- `emotion`：惊讶、尴尬、愤怒、疑惑、紧张、兴奋，可使用对应符号、表情变化和一次音效。
- `punchline`：吐槽、反转、误解、冷场和信息差，可使用重点字幕、较强漫画符号或短促音效，但之后必须留出理解和反应时间。

删除特效后如果不影响表达，就删除特效。优先级固定为：人物表演 → 反应镜头 → 字幕强化 → 漫画视觉特效 → 音效强化。

## 视觉反馈

允许按事件使用汗滴、黑线、青筋、震惊线、速度线、问号、感叹号、省略号、星星、闪光、局部背景简化/变色、集中线和短促屏幕震动。特效必须快速出现、完成表达并消失或随 CUT 结束；禁止默认挂载到所有镜头，也禁止持续循环播放。

重点字幕只强化关键词，不把每句对白都放大、弹跳或震动。人物表情是重点时，减少字幕和特效；特效是重点时，人物保持克制。屏幕震动只用于强烈震惊、反转、夸张吐槽或撞击，持续很短、幅度很小并快速恢复。

## 声音反馈

一个事件通常只选择一个主要音效，避免字幕、眨眼、手部动作和特效各自触发声音。音效类别可包括 CUT、强调、惊讶、尴尬、疑惑、出现、消失、漫画冲击和环境音。

环境音用于建立空间并保持低强度；场景未变化时不频繁切换。对白之间不要留数字静音：至少铺一层很低的室内底噪或音乐床，否则停顿会听起来像音频断了。背景音乐始终让位于对白，重要台词前可降低，笑点前可短暂减弱或停止，笑点音效结束后再按剧情恢复。

## 反应和静止

一句台词产生明显情绪时，优先 CUT 到另一个人物的反应镜头，而不是在原镜头叠加多种特效。反应镜头可以没有对白：静止、眼神移开、眼睛睁大、汗滴或“……”都可以承担表演。尴尬、无语、震惊和冷场时，静止本身就是演出，不得为了避免静态而加入漂浮、摆动或额外眨眼。

笑点优先使用以下节奏：

```text
正常对白 → 信息建立 → 短暂停顿 → 反转/吐槽 → 表情或反应 → 一个重点字幕或音效 → 停顿 → CUT
```

人物主要动作发生时不要同时堆叠大字幕、震动、集中线和多个音效。一个镜头只保留一个视觉重点。

### 视觉揭示与双关

笑点依赖画面信息（道具、位置、谁在哪里）时，揭示画面必须在笑点台词结束时或之前已经出现在屏幕上。不要让观众先在近景里听到双关、切到全景后立刻又接下一句台词。推荐做法：笑点台词直接放在能看到揭示物的镜头里，或者在台词结束的同一帧 CUT 到揭示镜头，再给 0.5–1 秒无对白的揭示停顿。揭示物本身最适合承担这个停顿里的唯一动作（例如木马摇一下、门自己关上），并配一个对应音效。

双关词在铺垫句和笑点句里使用同一种重点字幕样式（同一颜色或描边），让观众把两处联系起来；不要只强调其中一处。

### 收尾按钮

短剧结尾的最后一句如果是问句、反转或吐槽，后面需要一个“按钮”：被吐槽方的 reaction 镜头、一个表情变化或一次音效，然后再结束。不要在最后一句之后保持同一个无变化的画面直到片尾。

## 统一时间轴

所有视觉事件、音效和背景音乐变化继续写入同一个 `motion_plan.timeline`。例如：关键词开始 → 表情变化 → 重点字幕与音效出现 → 短震动 → 字幕恢复 → 保持表情 → CUT。禁止视觉特效和声音系统建立互相冲突的独立时间轴。

渲染器已经实现的字段和默认关闭原则见 [漫画表演运行时](performance-runtime.md)：符号、彩色关键词和震动只在用户明确要求时加入。

推荐的 Remotion 组件边界包括 `SubtitleEffect`、`ReactionEffect`、`ImpactEffect`、`QuestionEffect`、`EmbarrassmentEffect`、`ScreenShake`、`SoundEffect`、`AmbientSound` 和 `BackgroundMusic`。这些组件只在时间轴事件发生时渲染，不默认挂载到所有 Scene。

## 输出前检查

1. 每个特效是否能说明具体叙事作用？
2. 普通对白是否保持干净？
3. 重点字幕是否只突出关键词？
4. 一个事件是否避免堆叠多个音效？
5. 人物表演、反应镜头、字幕和特效是否争夺同一视觉重点？
6. 笑点或反转之后是否留有理解和反应停顿？依赖画面的笑点，揭示画面是否在台词结束前已出现？
7. 是否能用反应镜头替代特效？
8. 静止镜头是否被错误加入无意义动画？
9. 所有特效、音效和音乐变化是否来自同一时间轴？
10. 双关词在铺垫和笑点处是否使用同一种强调样式？结尾是否有反应按钮，而不是同一画面拖到片尾？

最终节奏应是：普通时安静，说话时自然，重点时明确，情绪时强化，笑点时爆发，爆发后重新安静。
