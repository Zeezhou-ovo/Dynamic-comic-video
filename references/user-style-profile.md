# 维护者已确认的沙雕漫画默认

## 适用范围

当本机用户继续其沙雕漫画系列、说“按之前标准/继续”，或没有指定其他画风时，采用本文件。它是该用户的个人默认，不约束其他用户或无关项目；用户当前这次的明确要求始终优先。

## 画面与人物

- 以二维简化搞笑漫画为主：粗黑清晰轮廓、平涂、少量阴影、夸张而戏谑的人类表情；不做写实熊猫毛发、3D、厚涂或精致日漫风。
- 延续已确认系列时复用熊猫头表情包人物和既有角色参考，保持头脸、耳朵、五官、服装及角色身份一致。新故事可换角色或地点，但应维持用户确认的简化沙雕画风。
- 延续宿舍故事时默认复用上下铺场景和两位躺在床上聊天的角色；复用现有场景素材，床、家具和背景物件位置保持稳定。
- 参考视频只提取粗线条、简化平涂、表情贴图、对白字幕等高层做法，不照搬其独有角色、镜头、台词、标志或水印。

## 镜头与表演

- 双人闲聊默认采用一个固定大全景连续呈现；不推镜、不平移、不摇镜、不缩放、不切镜。只有用户明确要求时才改镜头或构图。
- 场景和人物身体保持静止。优先用局部表情与嘴型微动表现说话，不让床、背景或人物整体漂移；不要擅自增加复杂肢体动作。
- 对白结构可采用铺垫、误解或升级、反转包袱、短暂停顿。按故事需要写简短自然的双人台词，不为套模板硬加句子。

## 嘴型、字幕与声音

- 嘴部素材是硬规则：禁止用图像生成/编辑模型、手绘、矢量或程序绘图生成、补画、重绘、扩张、变形或替换嘴部。只可使用用户提供并确认的该角色原嘴像素，允许局部裁切、对齐和透明图层合成；不得借用另一角色的嘴，不得拉伸或画椭圆制造张嘴。
- 只有在用户提供并确认了该角色自己的闭嘴与张嘴素材时，才可按说话区间切换两者；鼻子、眼睛、脸型、头部和身体保持不变。缺少张嘴素材时原嘴保持静止，不补画、不插值、不用别的素材代替，并在交付时说明。
- 无配音时可按台词估算字幕时间，但必须标为静音预演，不称为音画同步。嘴部素材缺失不阻止字幕和其他画面制作。
- 中文对白字幕放在画面下方，以粗白字和清晰黑色描边呈现，按说话顺序显示；生图素材中不烘焙对白、气泡、水印或标签。
- 默认只制作画面和字幕，不生成配音、音乐或音效。用户明确要求声音后再处理。

## 预览与流程

- 默认预览规格为 1280×720、60 fps；用户指定平台比例、清晰度或时长时随之调整。
- 先形成短剧情和双人台词，再排字幕/嘴型时间，复用并核对场景和角色素材，输出静音视频预览并检查关键帧。用户确认画面后，再按其要求继续加长剧情或制作声音版本。
